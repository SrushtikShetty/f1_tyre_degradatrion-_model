# F1 Tyre Degradation: Synthetic Benchmark and Research Protocol

## Scientific scope

This repository currently trains on a **synthetic F1-style race-state benchmark**, not authenticated historical Formula One telemetry. The authoritative training entry point is \`training/train_corrected_models.py\`; its default input is \`data/generated/authoritative_seed_20261004.csv\`. The target, \`next_lap_wear_increment\`, is generated by the simulator from current synthetic race state plus hidden simulator factors. It is a generated target, not a measured tyre-wear observation.

The repository also retains \`train.csv\` and \`test.csv\`, an older telemetry-shaped table with unverified provenance. Its legacy \`tire_wear_pct\` labels follow a deterministic compound-and-age schedule. Do not treat either legacy or current synthetic benchmark scores as evidence of real-world F1 accuracy.

The driver-aggression research extension is therefore structured as two distinct parts:
1. Reproducible evaluation and target-provenance audits on the current synthetic benchmark.
2. A separate, explicitly not-yet-run FastF1 protocol for testing whether telemetry-derived **driving intensity** improves a future-lap pace-change proxy on authenticated public race data.

The term *driving intensity* is used until construct validity supports a stronger interpretation. No steering-angle or brake-pressure channel is assumed.

## Current authoritative evaluation

The saved authoritative artifact is \`artifacts/evaluation/final_metrics.json\`. It records a 60-race synthetic benchmark (33,840 modelling rows), a chronological 36/12/12 race split, train-only preprocessing, and no race/stint overlap. On its synthetic final holdout, XGBoost reports \(R^2=0.9120\), MAE \(=0.07064\), and RMSE \(=0.09397\) in simulated wear-increment units. These are synthetic-simulator results only.

The active explainability artifact uses grouped permutation importance on validation MAE. The authoritative metrics explicitly record \`shap_computed: false\`; the current project does not compute SHAP values in this evaluation.

## Run the active synthetic benchmark

Install development dependencies, then from the repository root:

\`\`\`bash
python -m pip install -r requirements-dev.txt
python -m data_generation.generate_dataset --seed 20261004 --output data/generated/authoritative_seed_20261004.csv
python -m training.train_corrected_models --dataset data/generated/authoritative_seed_20261004.csv --seed 20261004
\`\`\`

Only after model and feature choices are frozen should the one-shot finalization command be used:

\`\`\`bash
python -m training.train_corrected_models --dataset data/generated/authoritative_seed_20261004.csv --seed 20261004 --finalize
\`\`\`

See \`docs/evaluation_protocol.md\` for the locked evaluation protocol.

## Driver-intensity study

The research assets in \`research/driver_aggression/\` specify the FastF1 data collection, telemetry feature definitions, prediction cutoff, alternative pace-proxy target, race-grouped evaluation, ablations, negative controls and report format. They are separate from the active synthetic training pipeline. Live FastF1 results must only be reported after running that experiment successfully with network access; the repository's saved synthetic scores are not substitutes.

Important signal limitations: FastF1 documents Speed, RPM, nGear, Throttle, binary Brake, DRS and position coordinates X/Y/Z. Coordinates may be interpolated when telemetry channels are merged. Steering angle, brake pressure and tyre-load measurements are not assumed available. See the official FastF1 source and the research README for the channel/processing caveats.

## API and explainability semantics

\`/api/model-metrics\` should serve the authoritative final-holdout metrics artifact, not stale legacy metric JSON. \`/api/feature-importance\` should serve the saved validation grouped-permutation artifact. \`/api/explain\` returns global feature-group associations; it is not a SHAP local explanation and must continue to say so.

## Data provenance

- \`data/generated/authoritative_seed_20261004.csv\`: synthetic benchmark generated by code in \`data_generation/\`.
- \`train.csv\` / \`test.csv\`: legacy telemetry-shaped tables with source provenance not established by the repository; the legacy wear labels are demonstrably constructed from compound and age.
- FastF1-derived race telemetry: not currently part of the authoritative benchmark training run.

See \`docs/data_provenance.md\` and \`docs/repository_paper_alignment_audit.md\`.
