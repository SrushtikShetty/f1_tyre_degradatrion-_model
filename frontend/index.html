Explainability

This system predicts the next-lap tyre-wear increment using a strict, causal feature set that excludes future-state race information. It incorporates lag features, rolling telemetry, race-grouped validation, and model-agnostic explainability based on saved feature importance data.

The project intentionally avoids future tyre wear, next-race conditions, finish position, and pit-stop outcomes. Driver aggression is included as a context variable in the causal prediction pipeline.
